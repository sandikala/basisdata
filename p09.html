P9AgregasiKonsep

Banyak baris, satu jawaban

Fungsi agregasi merangkum sekumpulan baris menjadi satu nilai.

FungsiMenghasilkan
COUNT()jumlah baris
SUM()total
AVG()rata-rata
MIN() / MAX()terkecil / terbesar
ROUND(x, n)pembulatan n desimal

Awas istilah kembarIni fungsi agregasi SQL. Agregasi di EERD (P2) adalah konsep diagram yang berbeda.
MIN dan MAX juga bekerja untuk teks (urut abjad) dan tanggal.
P9AgregasiContoh kode

Lima fungsi dalam satu query

  • WHERE menyaring dulu, baru dirangkum.
  • Beri alias dengan AS agar hasil mudah dibaca.
  • ROUND(AVG(...), 2) dari modul: bulatkan 2 desimal.
MariaDB [praktikum_db]>
SELECT COUNT(*)            AS jumlah,
       SUM(nilai)          AS total,
       ROUND(AVG(nilai),1) AS rata2,
       MIN(nilai)          AS terendah,
       MAX(nilai)          AS tertinggi
FROM nilai
WHERE kode_mk = 'BD01';

P9AgregasiCek pemahaman

Tabel mahasiswa punya 10 baris; 2 di antaranya tanggal_lahir NULL. Hasil SELECT COUNT(*), COUNT(tanggal_lahir) FROM mahasiswa;?

Pembahasan. COUNT(*) menghitung baris. COUNT(kolom) hanya menghitung nilai yang tidak NULL. Semua fungsi agregasi (kecuali COUNT(*)) mengabaikan NULL.
P9AgregasiKonsep

GROUP BY: rangkum per kelompok

Tanpa GROUP BY: satu jawaban untuk seluruh tabel. Dengan GROUP BY: satu jawaban per kelompok.

Rata-rata per mata kuliah
SELECT kode_mk, COUNT(*) AS peserta,
       ROUND(AVG(nilai), 1) AS rata2
FROM nilai
GROUP BY kode_mk
ORDER BY rata2 DESC;

P9AgregasiKonsep
WHERE vs HAVING
WHERE
Menyaring baris sebelum dikelompokkan. Tidak boleh berisi fungsi agregasi.
HAVING
Menyaring kelompok setelah GROUP BY. Boleh berisi fungsi agregasi.
Keduanya bersamaan
SELECT kode_mk, AVG(nilai) AS rata2
FROM nilai
WHERE nilai >= 60          -- buang nilai gagal dulu
GROUP BY kode_mk
HAVING AVG(nilai) > 80;    -- lalu pilih MK dengan rata-rata tinggi
P9AgregasiTantangan
Susun urutan klausa yang benar
Urutan menulis query.
Klik token untuk memindahkan ke baris jawaban (klik lagi untuk mengembalikan).
Jawaban:
P9AgregasiKonsep
Urutan menulis ≠ urutan dikerjakan
  1. FROM — ambil tabel
  2. WHERE — saring baris
  3. GROUP BY — kelompokkan
  4. HAVING — saring kelompok
  5. SELECT — hitung kolom & alias
  6. ORDER BY — urutkan
Akibatnya
Alias dari SELECT belum dikenal di WHERE, karena WHERE dikerjakan lebih dulu. Di ORDER BY alias sudah bisa dipakai.
P9AgregasiCari bug
Filter rata-rata yang gagal
Ada yang salah di kode ini. Temukan sebelum dosen membuka jawabannya.
Kode dengan bug
SELECT kode_mk, AVG(nilai) AS rata2
FROM nilai
WHERE AVG(nilai) > 80
GROUP BY kode_mk;
-- ERROR 1111: Invalid use of group function
Versi benar
SELECT kode_mk, AVG(nilai) AS rata2
FROM nilai
GROUP BY kode_mk
HAVING AVG(nilai) > 80;
Kenapa?Saat WHERE dikerjakan, kelompok belum terbentuk sehingga AVG belum bisa dihitung.
P9AgregasiCek pemahaman
Tampilkan jurusan yang punya minimal 3 mahasiswa. Klausa yang tepat setelah GROUP BY jurusan?
Pembahasan. Syarat terhadap hasil agregasi per kelompok → HAVING.
P9AgregasiCek pemahaman
Query SELECT jurusan, nama, COUNT(*) FROM mahasiswa GROUP BY jurusan; bermasalah karena…
Pembahasan. Satu kelompok jurusan punya banyak nama; mana yang ditampilkan? MySQL dengan ONLY_FULL_GROUP_BY menolaknya; MariaDB bawaan menampilkan nama acak, yang justru menyesatkan.

P9AgregasiPenutup
Rekap & exit ticket
Yang kita bawa pulang
  • Agregasi merangkum banyak baris menjadi satu nilai, mengabaikan NULL.
  • GROUP BY = satu hasil per kelompok.
  • WHERE menyaring baris, HAVING menyaring kelompok.
  • Urutan eksekusi: FROM → WHERE → GROUP BY → HAVING → SELECT → ORDER BY.
Exit ticket
Tulis satu query laporan untuk proyekmu yang memakai GROUP BY dan HAVING.
Jawab di Mentimeter (open ended) atau tulis di kertas kecil sebelum keluar kelas.
