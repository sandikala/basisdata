P5DDLContoh kode
Tabel dengan foreign key
Tabel induk (mahasiswa, matakuliah) dibuat dulu, baru tabel anak (nilai).
  • UNIQUE (nim, kode_mk): satu mahasiswa tidak dinilai dua kali untuk MK sama.
  • Tipe kolom FK harus sama dengan kolom yang dirujuk.
MariaDB [praktikum_db]>
CREATE TABLE matakuliah (
  kode_mk CHAR(4)      PRIMARY KEY,
  nama_mk VARCHAR(100) NOT NULL,
  sks     INT          NOT NULL CHECK (sks BETWEEN 1 AND 6)
);

CREATE TABLE nilai (
  id      INT AUTO_INCREMENT PRIMARY KEY,
  nim     CHAR(10) NOT NULL,
  kode_mk CHAR(4)  NOT NULL,
  nilai   INT CHECK (nilai BETWEEN 0 AND 100),
  UNIQUE (nim, kode_mk),
  FOREIGN KEY (nim)     REFERENCES mahasiswa(nim),
  FOREIGN KEY (kode_mk) REFERENCES matakuliah(kode_mk)
);
P5DDLCek pemahaman
Kampus ingin memastikan tidak ada dua mahasiswa memakai email yang sama. Constraint yang tepat?
Pembahasan. UNIQUE menolak nilai kembar. Kolom email bukan primary key, tetapi tetap harus unik.

P5DDLContoh kode
ALTER TABLE: renovasi tanpa merobohkan
  • ADD: tambah kolom.
  • MODIFY: ubah tipe/constraint.
  • CHANGE: ganti nama dan tipe sekaligus.
  • DROP COLUMN: hapus kolom beserta datanya.
Catatan versiRENAME COLUMN baru ada di MariaDB 10.5. Di XAMPP (10.4) pakai CHANGE.
MariaDB [praktikum_db]>
ALTER TABLE mahasiswa ADD email VARCHAR(100) UNIQUE;
ALTER TABLE mahasiswa MODIFY nama VARCHAR(150) NOT NULL;
ALTER TABLE mahasiswa CHANGE jurusan prodi VARCHAR(50);
ALTER TABLE mahasiswa DROP COLUMN email;
RENAME TABLE mahasiswa TO mhs;
P5DDLCek pemahaman
Kolom jurusan ingin diganti namanya menjadi prodi di XAMPP (MariaDB 10.4). Perintahnya…
Pembahasan. CHANGE menerima nama lama, nama baru, lalu tipe. MODIFY tidak bisa mengganti nama.

P5DDLCari bug
Menambahkan keterangan kolom
Contoh di modul. Coba jalankan di MariaDB, apa yang terjadi?
Kode dengan bug
COMMENT ON COLUMN Mahasiswa.NIM
  IS 'Nomor Induk Mahasiswa sebagai Primary Key';
Versi benar
ALTER TABLE mahasiswa
  MODIFY nim CHAR(10)
  COMMENT 'Nomor Induk Mahasiswa sebagai Primary Key';

-- keterangan tabel
ALTER TABLE mahasiswa COMMENT = 'Data induk mahasiswa';
SHOW FULL COLUMNS FROM mahasiswa;
Kenapa?COMMENT ON COLUMN adalah sintaks PostgreSQL/Oracle. MySQL dan MariaDB menaruh COMMENT pada definisi kolom.

P5DDLPenutup
Rekap & exit ticket
Yang kita bawa pulang
  • DDL mengurus struktur: CREATE, ALTER, DROP, TRUNCATE.
  • Constraint menjaga kualitas data sejak awal.
  • Buat tabel induk dulu, hapus tabel anak dulu.
  • Setiap DBMS punya dialek: COMMENT di MySQL berbeda dari PostgreSQL.
Exit ticket
Tuliskan satu ALTER TABLE yang akan kamu jalankan di proyek kelompok dan alasannya.
Jawab di Mentimeter (open ended) atau tulis di kertas kecil sebelum keluar kelas.
